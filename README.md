# CGPA-CALCULATOR-AND-TARGET-PLANNER
CGPA Calculator is a web application that helps students calculate their CGPA from semester-wise SGPAs. It includes performance graphs and a target CGPA planner to track academic progress. Built with HTML, CSS, JavaScript and Chart.js, it offers a clean, responsive and user-friendly experience.
# CGPA Calculator

A simple and responsive CGPA Calculator built to help students calculate their cumulative GPA easily without using spreadsheets or manual calculations. The application allows users to enter semester-wise SGPAs, calculate their overall CGPA, analyse their academic performance through graphs, and estimate the SGPA required to achieve a target CGPA.

## Why I Built This Project

As students, we often need to calculate our CGPA after every semester. Most of the available calculators online are either filled with advertisements or have a complicated interface. I wanted to build a clean and simple solution that focuses only on what students actually need.

This project was also developed as a frontend development project to improve my understanding of HTML, CSS, JavaScript, DOM manipulation, responsive design, and data visualization.

## Features

* Calculate CGPA using semester-wise SGPAs
* Support for up to 8 semesters
* Dynamic semester input generation
* Performance trend visualization using charts
* Target CGPA planner
* Responsive design for mobile, tablet, and desktop
* Dark and Light theme support
* Input validation and error handling
* Clean and modern user interface
* Instant calculation without page reload

## How It Works

1. Select the number of completed semesters.
2. Enter the SGPA obtained in each semester.
3. Click on "Calculate CGPA".
4. The application calculates and displays the overall CGPA.
5. A performance graph is generated to show semester-wise progress.
6. Users can enter a target CGPA to find the average SGPA required in the remaining semesters.
